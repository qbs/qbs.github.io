Qbs 3.4 released

Nov 12, 2026 by Christian Kandeler

The Qbs build tool version 3.4.0 is available.

What’s new

General

  • A new tool qbs-init was added. It creates a Qbs project from scratch.
  • The list-products command has a new --tags option.
  • The run command now releases the build graph, allowing a concurrent re-build.
  • The bundled QuickJS-NG was updated to version 0.16.2.
  • Qbs now uses bytecode cache when evaluating code. On Qbs itself, this speeds up resolving by 10% at a cost of additional memory consumption (2%-5%).

Language

We improved scanners: They can now attach properties to artifacts. These can then be accessed from rules via the new scannerId property.

C/C++ support

  • We improved our modules support:
    • Internal partitions can now be imported into implementation units.
    • Various mis-parsing were fixed that caused spurious detection of module and import statements.
  • The cpp.linkerVariant now supports the wild linker.
  • We added the new cpp.pchDependsOnSystemHeaders property to prevent pre-compiled headers breaking the build after a toolchain update.
  • We now support .def files with the MinGW toolchain (QBS-1869).

Qt Support

  • We adapted to the introduction of C++ modules support for moc in Qt 6.13.
  • QML modules are now properly supported via the new QmlModule item.

Code signing

There were a number of improvements in this area, namely:

  • Code signing support was added to BareMetal as well as the wix module.
  • Signing can now be done via the osslsigncode tool.
  • The NSIS and InnoSetup installers can now be signed.
  • Binaries created with MinGW can now be signed.

Try it

Qbs is available for download on the download page.

Please report issues in our bug tracker.

Join our Discord server for live discussions.

You can use our mailing list for questions and discussions.

The documentation and wiki are also good places to get started.

Qbs is also available from a number of package repositories (Chocolatey, MacPorts, Homebrew) and is updated on each release by the Qbs development team. It can also be installed through the native package management system on a number of Linux distributions. Please find a complete overview on repology.org.

Contribute

If you are a happy user of Qbs, please tell others about it. Maybe you would even like to contribute something yourself? Everything that makes Qbs better is highly appreciated. Contributions may consist of reporting bugs or fixing them right away, but new features are also very welcome. Your patches will be automatically sanity-checked, built and verified on Linux, macOS and Windows by our CI bot. Get started with instructions in the Qbs Wiki.

Qbs 2.5.1 released

Jan 28, 2024 by Ivan Komissarov

The Qbs build tool version 2.5.1 is available.

What’s new

This is a minor bugfix release that contains some fixes such as:

  • Fixed use of wrong declaration when looking up properties via the parent item (QBS-1821).
  • Fixed crash when resolving Probes.

Sources, binaries, etc can be found here.

This release of qbs is also part of Qt Creator 15.0.1.

Also, Qbs binaries are available via different package managers such as Chocolatey, Brew, macports and others.

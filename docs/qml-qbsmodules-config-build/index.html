    config.build

    Provides properties for configuring building. More...

    Since: Qbs 3.1
    • List of all members, including inherited members

    Detailed Description

    The config.build module contains properties that configure built-in items such as Application, Library, and Plugin.

    An example showing how change the default library type:

    qbs modules.config.build.libraryType:static

    For the list of available properties, see the ConfigBuild item.

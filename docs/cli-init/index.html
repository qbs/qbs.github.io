init

Synopsis

qbs create-project [--language <language>] [--version <version>] [--depends <depends>] project-type name

Description

Sets up a Qbs project directory according to the given options and parameters. The directory has the same name as the project and is generated in the current working directory.

Options

--language|-l <language>

The programming language to use. Possible values are c, c++, java, and objective-c. Defaults to c++.

--version <version>

The version of the product to create. Defaults to 1.0.0.

--depends <depends>

Comma-separated list of module dependencies to add to the product.

--help|-h|-?

Displays help for the command.

Parameters

<project-type>

The type of project to create. Possible values are application and library.

<name>

The name of the project and the generated directory.

Examples

To create a new C application:

qbs init -c c application hello-world

To create a new Qt-based library:

qbs init -d Qt.core library mylib
